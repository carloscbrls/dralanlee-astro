# AGENTS.md — Dr. Alan Lee DDS Website

## Project Overview
Dental practice website for Dr. Alan Lee in Manteca, CA. Built with Astro, hosted on Netlify.

## Architecture
- **Framework:** Astro (static site)
- **Hosting:** Netlify
- **DNS:** Cloudflare
- **Styling:** Tailwind CSS

## Key Conventions
- All pages must be WCAG 2.1 AA compliant
- Contact forms use Formspree
- SEO optimization for local dental keywords
- Mobile-first responsive design

## Important
- Never commit API keys or secrets
- Always test accessibility on changes
- Push to main triggers deployment
